# Website Personal Muhammad Huda

Website personal modern, dark aesthetic, responsive untuk desktop dan HP.

## Cara membuka
1. Extract folder.
2. Buka `index.html` dengan browser.
3. Untuk online, upload semua file ke GitHub lalu aktifkan GitHub Pages.

## Yang bisa diedit
- Nama: `index.html`
- Deskripsi: `index.html`
- Email dan GitHub: bagian Contact
- Warna utama: `style.css` pada `--accent`
- Foto: bisa ditambahkan kemudian ke bagian profile.
